# Material Flow & Takt Planner — Data & Privacy

The planner reads a source report selected by the user and produces planning outputs.

Recommended practice:

- Retain the source Cycle Time report JSON.
- Retain the planning assumptions with exported results.
- Keep source and planning versions together when traceability matters.
- Avoid entering unnecessary sensitive information.
- Verify organizational requirements before sharing production or customer data.
