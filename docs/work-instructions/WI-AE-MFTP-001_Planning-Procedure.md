# Material Flow & Takt Planner — Work Instructions

## 1. Import the Source Report

Use the report JSON from the Cycle Time & Labor Study. Confirm the imported study identity before proceeding.

## 2. Set the Planning Basis

Enter:

- Required production rate
- Net production hours per day
- Material-flow rate basis
- Inbound line-side coverage
- Finished-goods buffer coverage
- Cartons per finished pallet
- Timing basis

## 3. Review Capacity

Compare the required rate to labor bottleneck, cartoner rate, line/belt rate, and constrained maximum.

## 4. Review Material Flow

Confirm material identity, physical quantity per reference unit, pieces per supply skid, skid frequency, and line-side position requirements.

## 5. Review Finished Goods

Confirm pallet frequency and downstream buffer positions.

## 6. Export

Save the planning JSON and other required outputs with the source study record.
