# Abel Engineering Material Flow & Takt Planner

Current application version: **1.3**  
Planning export schema version: **1.0**  
Companion application: `991d81dc-7734-478c-b5c9-88b108dc1cd6.html`

## Purpose

The Abel Engineering Material Flow & Takt Planner is a standalone browser application that converts a validated Cycle Time & Labor Study report into process-capacity, material-consumption, supply-skid, finished-pallet, staging-space, and takt-planning outputs.

The planner is a downstream analysis tool. It does not collect raw timing samples and does not modify the imported source report. It reads the flattened Analysis Report JSON generated by the Abel Engineering Cycle Time & Labor Study.

## Intended Toolchain

The recommended data flow is:

1. Complete and validate a study in the Cycle Time & Labor Study application.
2. Download **Report JSON** from that application.
3. Import the Report JSON into the Material Flow & Takt Planner.
4. Enter demand, coverage, skid, pallet, and any manual-material assumptions.
5. Review process capacity, material demand, and storage requirements.
6. Export the Planning JSON, Material CSV, or vector PDF report.

Use the flattened Report JSON—not the editable Study JSON—as the planner input.

## Main Workflow

The planner is organized into four tabs.

### 1. Overview

Loads and identifies the source study, then establishes the planning basis.

Source details include:

- Study ID and study name
- Plant and line
- Job/SKU and shift
- Study date
- Equipment
- Source application and schema version

Planning inputs include:

- Required production rate in reference units per minute
- Net production hours per day
- Material-flow rate basis
- Optional custom material-flow rate
- Inbound line-side coverage hours
- Finished-goods buffer coverage hours
- Reference units per finished pallet
- Timing basis

### 2. Takt / Capacity

Compares required takt with measured process capability.

The capacity view includes:

- Required takt interval
- Labor bottleneck rate
- Primary machine/cartoner rate
- Belt-derived reference rate when available
- Constrained maximum rate
- Daily production comparisons
- Process-level timing and effective workload
- Current positions
- Recurring auxiliary labor burden
- Process capacity by role/station
- Takt-compliance status
- Vector process-takt chart

### 3. Material Flow

Converts process relationships and material quantities into consumption and handling requirements.

Material-planning capabilities include:

- Station-level material consumption
- Components per process event
- Process events per reference unit
- Material quantity per reference unit
- Pieces per hour and per day
- Pieces per supply skid
- Skids per hour
- Minutes of production per skid
- Equivalent and whole skids per day
- Estimated line-side skid positions for the selected coverage period
- Conflict detection when the same material has inconsistent skid quantities across source stations
- Manual material rows for items not represented in the source study
- Finished-pallet throughput and buffer positions

### 4. Data / Export

Provides compatibility information, source-field assessment, and planning outputs.

Available exports include:

- Planning JSON
- Material CSV
- Print / Save HD PDF

The PDF report uses vector text, tables, and a vector takt chart for resolution-independent output.

## Planning Basis

### Required takt

At a required rate greater than zero:

`required takt seconds = 60 ÷ required units per minute`

### Timing basis

The planner supports source timing bases including:

- Mean cycle time
- P90 cycle time
- Operator-weighted mean

The selected basis affects role workload and capacity calculations when the corresponding source statistic is available.

### Material-flow rate basis

Material and finished-goods calculations can be based on:

- Required production rate
- Constrained maximum rate
- Labor bottleneck rate
- Primary machine/cartoner rate
- Belt-derived reference rate
- Custom material rate

The selected rate basis should match the planning question. Use required rate for demand-driven storage planning; use a constrained or equipment rate when evaluating theoretical maximum flow.

## Process Capacity Model

For each paced process, the planner combines:

- Selected timing statistic
- Process events per reference unit
- Recurring auxiliary labor per reference unit
- Current positions

The resulting effective seconds per reference unit are compared with required takt. Process capacity is then expressed in reference units per minute.

The labor bottleneck is the active process with the lowest positive calculated capacity. The constrained maximum rate considers the available labor and machine/reference-rate signals represented in the imported report.

## Material Consumption Model

For each source station or manual material row:

`quantity/reference unit = process events/reference unit × components/process event`

At the selected material-flow rate:

`pieces/hour = quantity/reference unit × planning rate/min × 60`

`daily pieces = pieces/hour × net production hours/day`

When pieces per supply skid are known:

`skids/hour = pieces/hour ÷ pieces/supply skid`

`minutes/skid = 60 ÷ skids/hour`

Line-side skid positions are estimated from the chosen inbound coverage period. Values are planning requirements and should be checked against physical pallet dimensions, aisle requirements, material presentation, lift-truck access, and safety clearances.

## Finished-Goods Model

When reference units per finished pallet are provided, the planner calculates:

- Finished pallets per hour
- Minutes per finished pallet
- Finished pallets per day
- Finished-goods buffer positions for the selected coverage period

Finished-goods calculations use the selected Material Flow Rate Basis.

## Planner Exports

### Planning JSON

- Schema: `MPG.MaterialFlowTaktPlan`
- Schema version: `1.0`
- Application version: `1.3`

The existing schema name is retained for data compatibility even though the visible application is now branded Abel Engineering.

The planning package contains:

- Required-rate and takt assumptions
- Timing and material-flow basis selections

- Process-level capacity results

### Material CSV

Provides a flat material-planning table suitable for spreadsheet analysis, review, or downstream import.

The browser print workflow generates a formatted planning report containing vector text, tables, and a vector takt chart. Select a PDF destination in the browser print dialog to save the report.

## Local Storage

Planner assumptions and overrides are saved locally in the browser under:

`mpg_material_flow_takt_planner_v1`

The key name is retained for backward compatibility. Renaming it would disconnect users from their existing locally saved planner settings.

Local state can include:

- Required rate and production hours
- Timing basis
- Material-flow basis
- Coverage assumptions
- Finished-pallet quantity
- Station overrides
- Manual materials

Browser storage is specific to the browser, profile, and origin used to open the application. Clearing site data, switching profiles, or opening the file under a different origin can make previous planner settings unavailable.

## Recommended Operating Procedure

1. Complete the source study's data-quality and outlier review.
2. Export the source **Report JSON**.
3. Open the Material Flow & Takt Planner in a modern browser.
4. Import the Report JSON on the Overview tab.
5. Confirm the displayed Study ID, plant, line, job/SKU, date, and source version.
6. Enter the required production rate and net hours per day.
7. Select the timing basis and material-flow rate basis.
8. Review each process capacity against takt.
9. Enter or verify pieces per supply skid.
10. Resolve any conflicting skid quantities for shared materials.
11. Add manual materials that are not represented in the source report.
12. Enter finished-pallet quantity and coverage assumptions.
13. Review storage positions and material-handling cadence.
14. Export Planning JSON, Material CSV, and the PDF report as needed.

## Data-Quality Checks Before Use

Before relying on the planner results, confirm that the source study has:

- A correct reference unit
- A validated required or observed rate
- Correct process-event relationships
- Correct components per process event
- Representative timing samples
- Reviewed outliers and exclusions
- Correct active-position counts
- Correct recurring-task frequency models
- Supply-skid quantities where material-position planning is required

Within the planner, also confirm:

- The selected timing basis is available in the imported report.
- The selected rate basis is appropriate for the planning objective.
- Shared materials do not contain unresolved skid-quantity conflicts.
- Coverage hours reflect actual replenishment and staging policy.
- Finished-pallet quantity reflects the current pallet pattern.

## Browser Requirements

- Current Chromium-based browser, Firefox, or Safari
- JavaScript enabled
- Local storage enabled
- File-download permission for JSON and CSV exports
- Browser print/PDF capability

No installation, web server, database connection, or internet connection is required for normal operation.

## Functional Boundaries

- The planner depends on the accuracy and completeness of the imported Cycle Time & Labor Study report.
- Calculated capacity is an engineering planning estimate, not a guarantee of sustained production output.
- Material positions represent quantity-based coverage and do not automatically account for pallet dimensions, mixed-SKU rules, empty-container return, aisle space, ergonomic access, or fire-code constraints.
- A belt-derived or machine rate is a reference signal and may not represent the true sustained line constraint.
- Manual materials and station overrides are planner assumptions; document and review them before issuing a final plan.
- The planner is not the authoritative repository for raw timing observations.
